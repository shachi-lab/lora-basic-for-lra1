# Changelog

This is the English translation of the change history for LoRa-BASIC for LRA1, managed and published by Shachi-lab. The [Japanese version](CHANGELOG_jp.md) is the source document.

## v1.28.a

- Initial release managed by Shachi-lab.
- Established this version as the starting point of the new repository.
- Added a `CTRL` variable setting that starts `AUTO` quickly after wakeup from `DEEP`.
- Added the `Wan_BatLevel` variable.

Versions earlier than v1.28.a are outside the scope of this repository.
