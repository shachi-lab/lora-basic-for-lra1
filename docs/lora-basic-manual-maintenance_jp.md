# 概要

LoRa-BASICには、デバイス製造時のハードウェアの校正等に使用するコマンドや変数があります。  
これらのコマンドの実行や変数の操作は、不用意な操作を防止する目的で設定レベルを保守レベルにする必要があります。  

本マニュアルでは、設定レベルが保守レベルのときに実行可能なコマンドおよび設定可能な変数について解説します。 

---

# 設定レベル

LoRa-BASIC には設定レベルがあり、以下のようなレベルがあります。  

### 通常レベル(Level 0)

デバイスの電源投入およびシステムリセット後は「通常レベル」です。  
「通常レベル」では保守レベルおよび管理レベルのコマンドの実行や変数の設定はできません。

### 管理レベル(Level 1)

ユーザーによるパラメーター設定時に、不用意な設定値の変更を防止することを目的にしています。  
設定可能な変数については各リファレンスマニュアルを参照してください。

### 保守レベル(Level 2)

工場製造時の校正やハードウェア調整を目的としています。  
ユーザーによる使用は推奨されません。  
※ 保守レベルは、管理レベルを含みます。保守レベルでは管理レベルのすべての操作が可能です。  


設定レベルを変更するには、[*Pass*変数](#Pass) に特定の値を設定します。  
詳細は、*Pass* 変数の項目を参照してください。

# コマンド

## Txif

書式：Txif \[文字列\]

周期的にパケットを送信します。  
引数はSendコマンドと同じです。  
送信周期はPeriod変数で設定します。

## TxWave

書式：TxWave \[式\] 

連続して電波を送信します。  
引数の値が１０以上のときは、通常コマンドとして指定した時間のプリアンブル送信となります。  
設定レベルが保守レベル(Level 2)のときは、引数に４以下の値を指定することができます。

## Sens

書式：Sens \[式\]  

周期的(200msec)にRssiを計測して表示します。  
式 = 0 : ピーク / ＝1 : 平均値　  
引数が省略された場合は０が指定されたものとなります。  
Modem変数に従って、LoRaモードまたはFSKモードで受信します。  
（通常のキャリアセンスでは、Modem設定にかかわらず、FSKでキャリアセンスをします。）

帯域幅はBwの設定に従います。

# 変数

以下の変数は、設定レベルが保守レベルのときのみ設定が可能です。（*Pass* 変数を除く）  
通常レベルのときも参照は可能です。

## Pass

設定レベルを設定  
範囲：　なし  
- 999999 ： 管理レベル(Level 1)になります。  
- 123456 ： 保守レベル(Level 2)になります。  

上記以外の数値を設定すると「通常レベル」になります。  

参照時は以下の値となります。  
- 通常レベル = 0  
- 管理レベル = 1  
- 保守レベル = 2  

```
 >? Pass
 0
 OK
 >Pass=999999
 OK
 >? Pass
 1
 OK
```

## Level

キャリアセンスレベル  
範囲：-127～０  
キャリアセンスのレベルを設定します。

単位は(dBm)で、デフォルト値は-76(dBm)です。  
Ssaveでは保存されません。リセットや電源ONでデフォルト値になります。

## Drift

設定周波数の偏差  
範囲：-200～200  
周波数の偏差を設定します。単位は(100Hz)です。（Frq変数の単位と異なることに注意してください。）  
ただし、RFチップ(SX1276)のPLLへの設定ステップは32MHz/2^19
(61Hz)となります。  
設定と同時にFlashメモリに保存されます。

## Sn

シリアルナンバー  
範囲：100000～999999  
本モジュールのシリアルナンバーです。  
設定と同時にFlashメモリに保存されます。

## Period

Txifコマンドの送信間隔  
範囲：0～  
Txifコマンドでの送信間隔を(msec)単位で設定します。  
この送信間隔に送信時間は含まず、送信終了から時間の送信開始までの時間となります。  
Ssaveで保存され、システム起動時には自動的に読み込まれます。

## Frq

送受信周波数

範囲 ： 920600～928000  
送受信周波数を設定します。  
単位は（1kHz）です。  
Ch変数を設定すると、Frq変数は自動的にそのChに相当する値に設定されます。  
Ssaveで保存され、システム起動時には自動的に読み込まれます。
