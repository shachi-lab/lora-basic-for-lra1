# 英語版マニュアル作成時の確認メモ

日本語版4冊を原典として英語版を作成。日本語版は変更していない。
コマンド名、変数名、仕様値、動作説明、サンプルを原典に基づいて保持した。
サンプルコード91ブロックは、日本語の注釈を含めて原文を保持し、必要な英語の説明をブロック外に追加した。

## 原典の確認候補

以下は英訳で推測修正していない。原典を改訂する場合に確認するためのメモ。

| 冊子・項目 | 原典内の記述 |
|---|---|
| 保守編：管理レベル | 見出しは `Level l`（小文字のエル）、本文は `Level 1`。 |
| P2P編／保守編：TXWAVE | P2P編は引数の下限が5、保守編では5～9がエラー。 |
| P2P編：OWN | 一覧は0～65535、詳細は0～65534。転送例では65535を指定している。 |
| P2P編：CAD | タイムアウト引数について「0以下はタイムアウトなし」と「負数は絶対値でタイムアウト、表示なし」の両方が記載されている。 |
| P2P編：RXD／RXDW | 受信バッファの説明中に送信バッファやTXDW／TXDLの表記がある。 |
| P2P編：TXDサンプル | `Txd(10)`をDataの2byte目と説明している。 |
| 基本編：SLEEP | PA14の状態について本文のHighと表のLowが一致していない。 |
| 基本編：INT8／INT16／INT24 | 上位ビットを0にする説明と、符号付きの負数を含む戻り値の説明が併記されている。 |
| 基本編：BSWAP16 | サンプルの結果は `$34127856`。各16ビット内のバイトを交換する本文説明と照合が必要。 |
| 基本編：NEW／RUN／CTRL | 変数保持の説明では `$40` を指定しているが、CTRL表の該当ビットはクロック関連の説明。 |
| 基本編：DATETIME | 格納先の先頭インデックスは式2だが、表の注記は「引数1からのオフセット」。上限日時は原典どおり `88/19 03:14:05`。 |
| 基本編：UART2 | 起動条件の説明に `SLEEP/DEPP` と記載されている。 |
| 基本編：動作モード | 日本語原典の `REPLモード`／`RUNモード` を保持。READMEで使われているPROGへの置換は行っていない。 |

## 確認内容

- 翻訳対象2550行の対応を確認。
- 日本語版4冊が作業開始時と一致することを確認。
- コード91ブロックの内容を照合（改行形式を除き一致）。
- 本文に未翻訳の日本語が残っていないことを確認。
- HTML表の構造と文書内リンクを確認。
- 数値と識別子の抽出比較を使い、英語での綴りや別行への移動を含めて確認。

実装・ハードウェアでの動作検証は、この翻訳作業には含めていない。
